# SDWG GAME — прототип

Бесконечный бег к центру круглого города. Three.js, без сборки: статические файлы, работают в Safari на iPhone.

## Как устроено

- **Плоский мир + изгиб в шейдере.** Уровень — прямой коридор на сетке (12 колонок по кругу × ряды вперёд). В круг его сворачивает одна формула в вершинном шейдере (`js/render.js`): `r = L·e^(−dz/LZ)`, `φ = dx/L`, высота `y·e^(−dz/LZ)`. Поэтому стыков между кусками нет, а физика и столкновения считаются в плоском виде.
- **Паттерны** (`js/patterns.js`) — маленькие куски уровня, нарисованные текстом. Генератор (`js/world.js`) крутит их по кругу, зеркалит и стыкует как пазл.
- **Проверка проходимости** — каждый паттерн и каждая стыковка проверяются: за ряд максимум 1 колонка вбок, вверх максимум на 1 уровень, вниз можно с любой высоты, можно перепрыгнуть один ряд-провал.
- **Ярусы.** Улица, крыши (пол на 8 м, между домами пропасти) и подземка (пол на −6 м, потолок, трубы, бассейны, дыры в белую пустоту). На крышу забираются по предметам (будки → контейнеры → пристройка), спрыгнуть с крыши на улицу можно с любой высоты, в подземку ведёт рампа (`base` в `js/patterns.js`). В шейдере весь мир сходится к точке на высоте пола текущего яруса (`uB`), поэтому на крышах и в тоннеле путь выглядит так же, как на улице.
- **Верхушки небоскрёбов** (пол на 40 м): с обычных крыш туда подбрасывает красный трамплин (`L`) — полёт по рассчитанной дуге, приземление гарантировано. Наверху узкие крыши с ограждениями, балки между башнями, внизу город тонет в дымке, ветер сильнее. Обратно — прыжок вниз на обычные крыши.
- **Бег по стене** (как в VHOLUME): только по красным стенам (`w`). Свайп в её сторону — прилипаешь и разгоняешься, тебя плавно уводит вниз по дуге; свайп от стены (или вверх) — толчок прямо к красной стене напротив, прилипаешь сам: со стены на стену одним свайпом. Есть участки (длинный канал, пропасть, дыра в тоннеле), которые без бега по стене не пройти — проверка паттернов это учитывает.
- **Runner Vision** (как в Mirror's Edge): мир белый, красным выделено только то, чем пользуешься для движения: полосы на стенах для бега, кромки предметов, по которым забираться на крышу, трубы в тоннелях.
- **Препятствия — городские предметы:** будки, электрошкафы, ящики, контейнеры, пристройки, кондиционеры на крышах, пешеходные мосты с перилами.
- **Прыжок на скорости резче:** высота та же, но дальность не больше ~12 м, чтобы на разгоне не перелетать нужное место.
- **Деревья** — ствол, ветки и крона из отдельных плоских треугольников; растут в кадках вдоль улиц и на низких крышах.
- **Сид** в левом нижнем углу: `seed · паттерн #номер · ряд`. По этим цифрам можно воспроизвести любое место: `?seed=1234`.

## Параметры URL

- `?seed=1234` — конкретный город
- `?debug` — показать FPS
- `?bloom=0` — без блума и motion blur (если тормозит)
- `?blur=0` — без motion blur
- `?night=1` — сразу ночь (для проверки; обычно забег начинается днём, ночь наступает через ~35 с). Ночью на улице у бегуна фонарь, в подземке он гаснет
- `?weather=fog` — сразу туман (обычно погода меняется сама: ясно / туман, раз в 45–90 с)
- `?under=dark,balls,balloons,sparks,carts` — эти особенности подземки во всех переходах (обычно: первый переход обычный, дальше случайный набор)
- `?fx=0` — без цифрового шума и хроматической аберрации
- `?sound=0` — без звука (фоновая мелодия `audio/ambient.mp3` крутится в лупе)

## Обезьянки

Красные обезьянки (Suzanne из Blender, `models/monkey.bin` — сконвертирована из FBX в сжатые int16-вершины)
стоят поодиночке на клетках, куда точно можно добежать, не чаще чем раз в ~300 м (в среднем раз в ~600 м). Счётчик за забег —
в углу экрана, общий счёт хранится в браузере и виден после смерти.

## Запись забега

Каждый забег пишется целиком: касания и свайпы, действия, события физики (стена, толчок, длинный прыжок,
хват за край, трамплин, причина смерти) и состояние игрока и камеры ~30 раз в секунду, плюс карта рядов.
Кнопка ⚑ во время бега ставит метку «тут что-то не так». После смерти «Отправить запись» отдаёт
`sdwg-run-<сид>-<метры>m.json` в меню «Поделиться» (на iPhone — «Сохранить в Файлы» или мессенджер).
- `?auto` — автопилот (для тестов), `&ts=4` — ускорить время

## Локальный запуск

```
npx http-server game -p 8080
node game/tools/check-patterns.mjs   # проверка паттернов
```

## Деплой на Cloudflare

**Workers** (настройки в `wrangler.jsonc` в корне репозитория): Create → Import a repository → этот репозиторий,
Build command — пусто, Deploy command — `npx wrangler deploy`, ветка — та, где лежит игра.

**Pages**: Create → Pages → Connect to Git → этот репозиторий, Build command — пусто,
Build output directory — `game`.
