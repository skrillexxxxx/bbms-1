# SDWG GAME — прототип

Бесконечный бег к центру круглого города. Three.js, без сборки: статические файлы, работают в Safari на iPhone.

## Как устроено

- **Плоский мир + изгиб в шейдере.** Уровень — прямой коридор на сетке (12 колонок по кругу × ряды вперёд). В круг его сворачивает одна формула в вершинном шейдере (`js/render.js`): `r = L·e^(−dz/LZ)`, `φ = dx/L`, высота `y·e^(−dz/LZ)`. Поэтому стыков между кусками нет, а физика и столкновения считаются в плоском виде.
- **Паттерны** (`js/patterns.js`) — маленькие куски уровня, нарисованные текстом. Генератор (`js/world.js`) крутит их по кругу, зеркалит и стыкует как пазл.
- **Проверка проходимости** — каждый паттерн и каждая стыковка проверяются: за ряд максимум 1 колонка вбок, вверх максимум на 1 уровень, вниз можно с любой высоты, можно перепрыгнуть один ряд-провал.
- **Ярусы.** Улица, крыши (пол на 8 м, между домами пропасти) и подземка (пол на −6 м, потолок, трубы, бассейны, дыры в белую пустоту). На крышу забираются по предметам (будки → контейнеры → пристройка), спрыгнуть с крыши на улицу можно с любой высоты, в подземку ведёт рампа (`base` в `js/patterns.js`). В шейдере весь мир сходится к точке на высоте пола текущего яруса (`uB`), поэтому на крышах и в тоннеле путь выглядит так же, как на улице.
- **Верхушки небоскрёбов** (пол на 40 м): с обычных крыш туда подбрасывает красный трамплин (`L`) — полёт по рассчитанной дуге, приземление гарантировано. Наверху узкие крыши с ограждениями, балки между башнями, внизу город тонет в дымке, ветер сильнее. Обратно — прыжок вниз на обычные крыши.
- **Бег по стене** (как в VHOLUME): только по красным стенам (`w`). Свайп в её сторону — прилипаешь и разгоняешься, тебя плавно уводит вниз по дуге; свайп от стены (или вверх) — толчок прямо к красной стене напротив, прилипаешь сам: со стены на стену одним свайпом. Есть участки (длинный канал, пропасть, дыра в тоннеле), которые без бега по стене не пройти — проверка паттернов это учитывает.
- **Runner Vision** (как в Mirror's Edge): мир белый, красным выделено только то, чем пользуешься для движения: полосы на стенах для бега, кромки предметов, по которым забираться на крышу, трубы в тоннелях.
- **Препятствия — городские предметы:** будки, электрошкафы, ящики, контейнеры, пристройки, кондиционеры на крышах, пешеходные мосты с перилами.
- **Прыжок на скорости резче:** высота та же, но дальность не больше ~12 м, чтобы на разгоне не перелетать нужное место.
- **Деревья** — ствол, ветки и крона из отдельных плоских треугольников; растут в кадках вдоль улиц и на низких крышах.
- **Сид** в левом нижнем углу: `seed · паттерн #номер · ряд`. По этим цифрам можно воспроизвести любое место: `?seed=1234`.

## Параметры URL

- `?seed=1234` — конкретный город
- `?debug` — показать FPS
- `?bloom=0` — без блума и motion blur (если тормозит)
- `?blur=0` — без motion blur
- `?night=1` — сразу ночь (для проверки; обычно забег начинается днём, ночь наступает через ~35 с). Ночью на улице у бегуна фонарь, в подземке он гаснет
- `?weather=fog` — сразу туман (обычно погода меняется сама: ясно / туман, раз в 45–90 с); `?weather=rain` — дождь, пока только для проверки
- `?ruin=1` — разруха (отключена в обычной игре, только для проверки)
- кнопка «PS1» в меню — экспериментально: вершины липнут к грубой сетке экрана, меш дрожит, как на PlayStation 1
- цвет на выходе — ACES Filmic; кнопка «Автоэкспозиция» (кадр ужимается до 16×9, средняя яркость читается асинхронно; глаз привыкает к свету за ~0.5 с, к темноте за ~2 с)
- `?under=dark,balls,balloons,sparks,carts` — эти особенности подземки во всех переходах (обычно: первый переход обычный, дальше случайный набор)
- `?fx=0` — без цифрового шума и хроматической аберрации
- `?sound=0` — без звука (фоновая мелодия `audio/ambient.mp3` крутится в лупе)

## Поток и очки

Главный рекорд — **очки**: каждый пробежанный метр умножается на текущий **множитель потока**.

- HUD потока — снизу по центру (в угол экрана в беге смотреть некогда): очки · ×множитель · км/ч,
  под ними длинная полоска — сколько осталось до обрыва; тает к центру, в последнюю секунду мигает; на ×2, ×3… множитель
  подпрыгивает; «+N км/ч» всплывает над ними. Пока внизу подсказка обучения — спрятан. Метры и обезьянки — мелко слева сверху.
- Множитель растёт, пока скользишь — в подкате или на красной стене: +0.03 в секунду на стартовой скорости
  (40 км/ч), на вдвое большей — вдвое быстрее (`FLOW_RATE` в `js/main.js`). Предела нет.
- Больше 3 с на ногах (`FLOW_GRACE`) — поток рвётся, множитель снова ×1. Полоска под множителем в HUD показывает,
  сколько осталось. Обычный прыжок считается как бег по земле; высокий полёт (с крыши, трамплин, над пропастью) — пауза.
- Скорость (разгон и накачка) в полёте не тает — только на ногах по земле.
- **Приземление в подкат**: свайп вниз в воздухе (или подкат в первые 0.15 с после касания) — перепад высоты
  от верхней точки полёта превращается в скорость: `2·√(перепад − 2)` м/с, от перепада 4.4 м
  (крыша → улица ≈ +18 км/ч, небоскрёб → крыша ≈ +40). У спидометра всплывает «+N км/ч», полосы скорости, «вжух».
- **Жёстко на ноги** (перепад от 7.5 м, крыша → улица): спотыкаешься — скорость проседает, как после зацепа,
  накачка вдвое меньше, поток рвётся сразу.
- Первое падение с крыши — один раз подсказка «Приземлись в подкат» с замедлением (`sdwg-tut-land`).
- Экран смерти: очки, метры, макс. множитель, самый долгий поток, рекорд очков (`city-best-score`) и подсказка
  о том, чего не хватило (споткнулся / не разгонялся / мало скользил).
- «Рекорды» — **рекорды дня**: очки, метры, км/ч, обезьянки за сегодня; в полночь по Москве (UTC+3) у всех нули.
  В таблице все игроки, у кого сегодня забегов не было — нули; под заголовком — сколько осталось до обнуления.
  Игра копит их в `sdwg-day` + `sdwg-day-stats` (уходят на сервер с прогрессом), экран смерти показывает рекорды дня.
  На сервере колонки `day` и `score` (в уже созданной базе добавляются сами); рекорды за всё время (`city-best*`,
  `sdwg-monkeys`) по-прежнему хранятся в прогрессе, но в таблице не показываются.

## Город дня

Один сид на всех на сутки: `dailySeed()` в `js/main.js` — хеш даты по Москве (UTC+3), сервер для этого не нужен.

**Два режима.** Город дня — главный (соревнование): в меню большая залитая красная кнопка, под ней «одна карта на всех ·
новая через N ч» (новичку — «сначала — короткое обучение»: кнопка запускает обучение свободным забегом). Свободный забег —
вторая кнопка (город с фона меню, «Мои сиды» и т. п.). Тап по фону меню забег больше не начинает; Enter/пробел — город дня.
У режимов разные экраны смерти: город дня — «Ещё раз» (залитая), «Рекорды», «Главное меню» и сразу таблица города дня
(топ-7 по очкам, ты красным, «ты 8-й из 9»; точка у ника — цвет его призрака; без аккаунта — строка «ты» и «Войди — и ты
в таблице»); свободный — «Новый город», «Этот же сид», «Город дня», «Сохранить сид», «Мои сиды»…

- Забег в городе дня начинается сразу в городе (без проспекта из меню и без обучения) — у всех одинаковый старт.
  В HUD слева метка «Город дня».
- Экран смерти: твой рекорд сегодня в городе дня и «место N из M» (когда ответит сервер; нужен аккаунт);
  «Ещё раз» вместо «Этот же сид» — снова сегодняшний город (после полуночи — уже новый). «Новый город» и
  «Главное меню» выводят из режима.
- Рекорды города дня — поля `cScore`, `cDist`, `cSpeed`, `cMonkeys` в `sdwg-day-stats`; на сервере колонки
  `c_score`, `c_dist`, `c_speed`, `c_monkeys` (добавляются сами). В «Рекордах» переключатель «Все города / Город дня»
  (`GET …&board=city`); из забега в городе дня открывается сразу его таблица. Обнуляются в полночь, как и остальные.

### Призрак

В городе дня бегут **призраки — полупрозрачные обезьянки** (та же модель, что у собираемых): топ-5 дня с сервера
и твой лучший забег. У каждого свой цвет по месту (лидер — красный, дальше синий, оранжевый, зелёный, фиолетовый) и ник
над головой того же цвета (свой — «ты»). Бегут в том же темпе — по времени от старта, поэтому трек, пришедший с опозданием,
просто появляется там, где этот игрок был в эту секунду; к «Ещё раз» треки уже в памяти, из меню грузятся заранее.
Смотрят назад, на тебя; разбился — растворяется. Мир к центру сжимается быстро (на 50 м — в 20 раз), поэтому вдали
призрак крупнее (до ×10) — остаётся заметным пятном своего цвета; ник виден до ~160 м. Под полоской потока — ближайший
впереди, кого догонять: «Masha ▲ 35 м» (его цветом); впереди никого — ближайший позади «▼».

- Свой забег в городе дня пишется каждые 0.1 с (x, y, z ×100 и подкат). Побил свой рекорд в городе дня —
  трек уходит на сервер (`POST action: 'ghost'`, разностями от предыдущей точки, до 15 минут). Нужен аккаунт.
- Сервер хранит один трек на игрока в день (лучший), вчерашние удаляет; `GET ?ghost=1` — треки топ-5 дня.
  Трек скачивается при каждом старте забега в городе дня.
- Свой лучший трек дня хранится и на телефоне (`ghost-own`, не синхронизируется — большой): призрак есть и без аккаунта,
  и сразу после рекорда. Призрак — лучший из двух: свой или лидера. Свой стартует вместе с тобой (в камере его не видно):
  он впереди, когда ты медленнее своего рекорда, позади (▼) — когда быстрее.

## Обезьянки

Красные обезьянки (Suzanne из Blender, `models/monkey.bin` — сконвертирована из FBX в сжатые int16-вершины)
стоят поодиночке на клетках, куда точно можно добежать, не чаще чем раз в ~300 м (в среднем раз в ~600 м). Счётчик за забег —
в углу экрана, общий счёт хранится в браузере и виден после смерти.

## Запись забега

Каждый забег пишется целиком: касания и свайпы, действия, события физики (стена, толчок, длинный прыжок,
хват за край, трамплин, причина смерти) и состояние игрока и камеры ~30 раз в секунду, плюс карта рядов.
Кнопка ⚑ во время бега ставит метку «тут что-то не так». После смерти «Отправить запись» отдаёт
`sdwg-run-<сид>-<метры>m.json` в меню «Поделиться» (на iPhone — «Сохранить в Файлы» или мессенджер).
- `?auto` — автопилот (для тестов), `&ts=4` — ускорить время

## Аккаунт и общая таблица рекордов

Аккаунт — ник + пароль. При первом запуске игра предлагает его завести («Позже» — спросит при следующем
запуске), на другом устройстве — «Уже есть аккаунт? Войти». Ник, который выглядит или читается так же,
как чужой («Ivan» / «lvan» / «IVAN_» / «Иван»), занять нельзя. Пароль хранится только как хеш;
после 5 неверных попыток вход по нику закрыт на 10 минут.

Прогресс (рекорды, обезьянки, «Мои города», настройки) синхронизируется с сервером при запуске и после
каждого забега и объединяется между устройствами: рекорды и обезьянки — максимум, города — все вместе,
настройки — с последнего устройства. «Выйти из аккаунта» (кнопка «Аккаунт» в «Рекордах») стирает
прогресс с устройства — он остаётся на сервере.

«Рекорды» — в главном меню и на экране смерти: таблица «место · игрок · метры · км/ч · обезьянки»,
тап по заголовку колонки — сортировка по ней.

Сервер — Cloudflare Pages Function `functions/api/leaderboard.js` (в корне репозитория) и база D1:
1. Cloudflare → Storage & Databases → D1 → Create → имя, например, `sdwg-leaderboard`.
2. Pages → проект → Settings → Bindings → Add → D1 database: Variable name `DB`, база из шага 1
   (для Production и Preview).
3. Передеплоить (Deployments → Retry deployment или новый пуш). Таблицы в базе создаются сами.

Проверка: `https://sdwggame.pages.dev/api/leaderboard` → `{"top":[],"me":null}` — база подключена,
`{"error":"nodb"}` — нет привязки `DB` (или после неё ещё не было деплоя: подойдёт любой пуш в ветку).
Без привязки игра работает как раньше, а экраны пишут «Таблица рекордов пока не подключена».
`?nick=0` — не спрашивать ник при запуске.
`?boot=0` — без экрана запуска («Tap» / окно установки) — сразу в игру (для тестов; с `?auto` он тоже пропускается).

## Локальный запуск

```
npx http-server game -p 8080
node game/tools/check-patterns.mjs   # проверка паттернов
```

## Деплой на Cloudflare

**Workers** (настройки в `wrangler.jsonc` в корне репозитория): Create → Import a repository → этот репозиторий,
Build command — пусто, Deploy command — `npx wrangler deploy`, ветка — та, где лежит игра.

**Pages**: Create → Pages → Connect to Git → этот репозиторий, Build command — пусто,
Build output directory — `game`.
